# Release review, 13 September 2026

Status: preparation, not publication approval. The full hardware protocol is
still partial. Choosing an experimental release must be an explicit maintainer
decision; this review does not change that gate.

The retained candidate uses project revision
`9b2ebcaaa95bcaa8a3714987fc5d475479b10226`. Its seven release-draft assets
were downloaded and checked against their GitHub SHA-256 digests. All files
listed in the source bundle's checksum inventory and all 126 downloaded source
archives passed their individual checks.

The public kernel image's legacy header and payload CRCs passed. Its nested
XZ initramfs was decoded without executing or extracting filesystem entries.
The 1,005 entries contain the reviewed public network, DHCP, firewall and
Dropbear defaults, no SSH host-key or authorization files, and no tested private
deployment hostname or address. Private-key header strings in libmbedcrypto
are parser constants, not embedded private keys. This is a scoped inspection,
not a proof that an arbitrary secret cannot exist anywhere in a binary.

The example companion has six entries, all directories or configuration data.
It is not the private companion used during the hardware test.

The original notice archive has 400 hash-verified entries from 110 source
archives. The notice selection now also retains original copyright-bearing
source files from eleven packages whose notices are in source headers rather
than separately named license files. Original files and third-party attribution
are preserved, including components with different terms within one package.

The [package map](release-package-map-20260913.json) resolves all 141 installed
packages to retained, hash-checked sources. It distinguishes package metadata
from original component terms. In particular, libc, libpthread and librt come
from musl, not GCC. The map deliberately does not turn metadata declarations
into automatic legal approval.

selection. The second retains 135 original files from the verified OpenWrt
archive: its LICENSES directory, builtin base-files, mtd, urandom-seed and
gpio-button-hotplug sources, and the firewall4, keyring and toolchain recipes.
Each supplement has a member-to-source checksum index. Firewall4 and keyring
lack separate notices in their downloaded archives; their original recipe
declarations are preserved without inventing upstream attribution.

Remaining publication steps:

- Review this change and retain the supplements and review record alongside
  the existing sources and binaries in the release draft.
- Agree on release qualification. The [hardware report](native-hardware-20260912.md)
  remains partial; no full-support claim is justified. The firmware is not a
  completed backup appliance and does not promise working WoL.
- Publish only after that decision and a final check of the draft's asset
  inventory. This review has not published or replaced any release asset.

Build reproducibility is no longer an open blocker. The independent offline
rebuild and main-branch A/B check are linked in
[distribution.md](../distribution.md). They do not substitute for license review
or physical tests.
